## What is OMO Adaptive?

OMO Adaptive is a multi-harness agent orchestration project. Its Claude Code plugin adds:

- Adaptive execution effort based on task size and risk
- Claude-native specialist agents for discovery, implementation, planning, QA, and review
- Reusable skills for security research, technical-debt analysis, PR work, and release preparation
- Explicit safety gates around destructive changes, merges, pushes, publishing, and external notifications
- Artifact-backed verification before work is reported complete
